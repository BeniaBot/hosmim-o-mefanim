# חוסמים או מפנים

**משחק אסטרטגיה סאטירי בעברית ובתלת-ממד.** צומת אחד, אחר צהריים אחד:
המפגינים רוצים להגיע לכותרות לפני השקיעה, והמשטרה רוצה שהשמש תשקע קודם.

עובד **בלי אינטרנט** ובלי התקנה: פותחים את `index.html` בדפדפן, או בונים קובץ EXE אחד (ראו למטה).

## איך משחקים
- **המטרה**: כל עוד יש פקק, **מד הכותרות** עולה. 100 = המפגינים ניצחו. השמש שקעה לפני כן = המשטרה ניצחה.
- **כמפגינים**: בוחרים חוליה (לחיצה על השלט שלה) ולוחצים על הכביש. החוליה נפרסת לרוחב הכביש — האדום מראה אילו נתיבים ייחסמו. "לשבת" (S) מקשה על הפינוי. מזמינים תגבורת מהלוח בפינה.
- **כמשטרה**: בוחרים כוח ולוחצים על חוליית מפגינים. שוטרים גוררים לניידת, פרשים מפזרים עומדים, מכת"זית מתיזה על כולם. כוח מופרז מגיע לחדשות.
- **שלוש מפות**: צומת בר אילן → כביש 4 → גשר המיתרים. כל מפה נפתחת אחרי ניצחון בקודמת.
- מקלדת: 1–9 בחירת חוליה · Z X C B N V הזמנות וכלים · S לשבת/לקום · F "יש לי אישור" · רווח הפסקה · WASD/חיצים מצלמה · Q/E סיבוב · גלגלת זום.

## בניית קובץ EXE
ההוראות המלאות בעברית: [`desktop/BUILD.md`](desktop/BUILD.md). בקצרה: Node.js מותקן → לחיצה כפולה על `desktop\build.bat`.
