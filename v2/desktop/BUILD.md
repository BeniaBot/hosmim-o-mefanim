# איך בונים קובץ EXE אחד מהמשחק

הקובץ שנבנה עובד בכל מחשב ווינדוס, בלי אינטרנט ובלי התקנה: לחיצה כפולה ומשחקים.

## פעם ראשונה בלבד
1. להתקין **Node.js** (הגרסה המומלצת) מהאתר הרשמי שלו. אחרי ההתקנה — להפעיל את המחשב מחדש.

## בכל פעם שרוצים קובץ חדש
1. להוריד את הענף מהמאגר (כפתור Code ← Download ZIP) ולחלץ.
2. להיכנס לתיקייה `v2\desktop`.
3. **לחיצה כפולה על `build.bat`**.
4. לחכות. בפעם הראשונה זה לוקח כמה דקות (מורידים את כלי הבנייה פעם אחת).
5. בסוף נפתחת התיקייה `v2\desktop\dist` ובה הקובץ **`חוסמים או מפנים.exe`**.

## כשמפעילים את הקובץ במחשב אחר
ווינדוס עלול להציג "Windows protected your PC", כי הקובץ לא חתום בחתימה מסחרית.
לוחצים **More info** ואז **Run anyway**.

## אם משהו נכשל
מצלמים את החלון השחור ושולחים — ההודעה שם אומרת מה קרה.

## בלי לבנות בכלל
אפשר גם פשוט לפתוח את `v2\index.html` בדפדפן (לחיצה כפולה). עובד בלי אינטרנט.
